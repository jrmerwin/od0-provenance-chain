# 5. Definitions (unchanged from v0.1)

## 5.1 Source model family

𝔐 = (X, x₀, T, Γ, O, τ, R): state schema, genesis state, transition/constructor, control domain, opportunity/selection interface, index/clock metadata, persistent read/write fields. Absent components are recorded ABSENT, never inferred.

## 5.2 Source-complete global maturation model — criteria GM1–GM12

- **GM1** exact global state carried between updates.
- **GM2** source-declared genesis state or classified initial family.
- **GM3** global transition/constructor (enumeration order alone is not a transition).
- **GM4** opportunity and action status defined, or the process explicitly classified externally controlled. Missing opportunity cannot be filled by a no-op or uniform law.
- **GM5** persistence: state retains every field read by future updates; recomputed summaries count only with an exact reconstruction proof.
- **GM6** origin-to-late closure: one state/transition family covers early and late domains, or exact source maps between stages exist.
- **GM7** exact map F: X_global → Z_OD0 recovering a legal OD0 prestate and its semantic objects.
- **GM8** commuting local law: restriction commutes with the frozen local transition; multi-occurrence global updates need an explicit decomposition/order theorem.
- **GM9** availability: the global state determines which OD0 full controls, histories, service interfaces, or carrier labels are legal, or full availability is proved. Enumerating all controls does not pass.
- **GM10** source covariance under declared symmetries.
- **GM11** epoch-state read relevance: at least one global field can in principle distinguish developmental regimes. A bare external counter does not pass.
- **GM12** no target-derived definition: nothing selected from broadening labels, onset numbers, proton absence, or cosmology fits.

## 5.4 Intrinsic maturation observable

A source-derived M: X_global → Y_M with: exact state derivation; gauge invariance or proved covariance; no dependence on filenames, iteration order, wall time, or supplied epoch labels; no use of future particle/collision/cosmology outcomes; read/write or availability relevance; deterministic serialization; declared relation to the transition. R48 freezes the candidate inventory or proves none exists; it does not prove an epoch partition.

Not assumed scalar. May be a finite partition, filtration, support stratum, legal-alphabet change, quotient-dimension change, stable basin, or vector of developmental fields. The historical four-stage labels are not assumed exhaustive or linearly ordered. No mature basin is proposed in R48.
